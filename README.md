# Z-Agent

A personal AI agent built by **Bolo67-ctrl**.

## Vision
Z-Agent turns natural-language requests into useful work: reasoning, planning, tool use, coding, research, file work, and multi-step tasks.

## Stack
- Next.js
- TypeScript
- React
- Vercel AI SDK
